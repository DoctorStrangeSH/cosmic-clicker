# 🚀 Cosmic Clicker - Кристаллис-X9

Эпический космический кликер для Telegram Mini Apps.

## 🎮 Возможности

- 💎 Бесконечная прогрессия
- 🏗️ 50+ зданий в 5 тирах
- ⚡ Система улучшений
- 🌑 Престиж-система
- 🏆 100+ достижений
- 📋 Ежедневные квесты
- 🐾 Питомцы с эволюцией
- 🚀 Флот кораблей
- ⚔️ Боевая система
- 🏰 Подземелья
- 🔮 Магия и заклинания
- 👷 Профессии
- 📊 Торговый рынок
- 👥 Социальный центр

## 🛠️ Технологии

- React 18
- TypeScript
- Zustand (state management)
- Framer Motion (анимации)
- Howler.js (звук)
- Vite (сборка)

## 📦 Установка

```bash
# Клонируем репозиторий
git clone https://github.com/yourusername/cosmic-clicker.git

# Переходим в директорию
cd cosmic-clicker

# Устанавливаем зависимости
npm install

# Запускаем dev-сервер
npm run dev
